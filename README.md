# Apollo SuperAGI Toolkit

This repository contains a custom integration for SuperAGI that provides an Apollo API tool for fetching leads based on search queries. It is designed to work within the SuperAGI framework and demonstrates how to create custom tools by integrating with Apollo.io.

## Files
- `__init__.py`: Marks the directory as a Python package.
- `apollo_tool.py`: Contains the main logic to connect to Apollo.io’s API.
- `apollo_toolkit.py`: Registers the Apollo tool within SuperAGI.
- `requirements.txt`: Lists the dependency (`requests`) needed for this integration.

## Setup
1. Clone the repository.
2. Add your Apollo API key via the SuperAGI dashboard configuration for the tool.
3. Sync the tool in SuperAGI and test a sample query.

## Usage
Use this tool to perform lead searches on Apollo.io. Pass a search query to fetch company data based on specific criteria.

Enjoy!
